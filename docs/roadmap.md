# ThoroughLoop Roadmap

This roadmap keeps the product focused on founder operating diagnosis.

## Now

- Harden the web MVP.
- Expand focused tests for `packages/core`.
- Keep CI healthy.
- Prepare Vercel deployment without adding secrets or backend infrastructure.
- Preserve local-first persistence and legacy storage keys.

## Next

- Add better synthetic examples for workflow testing and demos.
- Add export or share paths for founder memos.
- Improve review cadence around saved decisions.
- Improve empty and error states as real usage patterns emerge.
- Consider an optional account layer only after the single-user loop is validated.

## Later

- Backend persistence.
- Auth.
- Team workspace support.
- External integrations.
- Server-side AI generation.
- Full Expo mobile app.
- Cross-device sync.

## Explicitly Not Now

- CRM replacement.
- Project management suite.
- Heavy dashboard.
- Investor relations platform.
- Notion clone.
- Payments.
- Large integration marketplace.
- Mobile dependency audit inside unrelated web MVP hardening work.
