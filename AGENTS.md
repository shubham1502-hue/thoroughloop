2. Keep product logic in packages/core.
3. Keep UI reusable where practical.

5. Use storage adapters for persistence.
6. Do not add backend, auth, database, payments, external APIs, or integrations unless explicitly requested later.
7. Use "founder action" instead of "task".
8. Use "memo" instead of "report".
9. Use "diagnosis" instead of "analysis".
10. Use "workflow" instead of "module".
11. Do not use emojis.
12. Do not use em dash characters.
13. Run lint, typecheck, and build before completion.
14. Keep the code simple, readable, and maintainable.
